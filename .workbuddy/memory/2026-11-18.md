## 多显示器托盘弹窗定位修复（重要）

- 症状：点击 B 屏托盘，弹窗在 A 屏出现。根因：TrayIconEvent rect 是物理坐标（乘了托盘屏 backingScaleFactor），tao 的 monitor_from_point 按 CGDisplayBounds（全局点空间）匹配；缩放>1 的屏上物理坐标在点空间越界 → 匹配失败 → 回退主屏。
- 深层：tao Monitor::position()/size() = CG点×本屏缩放，混合 DPI 下各屏物理空间不统一，物理坐标直接夹紧也不可靠。
- 修复（tray.rs position_near_tray）：macOS 分支遍历 available_monitors，用各屏自己的 scale 还原 CG 点边界（position/scale），图标物理坐标÷该屏 scale 落进哪块屏的点边界即命中；定位全程点空间，set_position 传 LogicalPosition（tao 对 Logical 变体原样透传 NSWindow，不受窗口当前屏 scale 二次换算影响）。非 macOS 保持 monitor_from_point + PhysicalPosition。clamp 换 max→min 防极小屏 panic。
